Harness Quest

참가자 교재 열기

OpenCode 1.x는 사용자 선택 사항이며 검증 기준은 1.19.4입니다. 실제 실행기 연동 검사를 통과했고, 실제 모델과 사람이 조작하는 승인 화면의 리허설은 남아 있습니다.

실험실 · 라이브 + 미리보기

Hook·Harness 실험실

요청을 보내면 OpenCode가 도구를 호출하고, Hook과 Harness가 그 호출을 어떻게 판단하는지 흐름도와 로그로 보여 줍니다. 규칙(도구·경로·예산·검증·승인)을 화면에서 바꿔 볼 수 있습니다. 이 페이지에서 열면 브라우저 모의 실행으로 동작하고, 저장소 루트에서 node lab/server.mjs를 실행하면 실제 OpenCode로 동작합니다.
