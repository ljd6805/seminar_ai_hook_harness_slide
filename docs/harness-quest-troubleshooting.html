실습 중 증상별 점검

증상확인과 복구
quest 도구가 없음실습 폴더에서 실행했는지, 활성 Agent가 quest인지, .opencode 의존성이 설치됐는지 확인합니다. opencode --version과 debug config를 확인하고 재시작합니다.
수정한 규칙이 적용되지 않음정책 모듈은 프로세스에 로드됩니다. 파일 저장 후 OpenCode를 완전히 종료하고 다시 시작하세요. checkpoint 후에는 새 세션을 사용합니다.
로컬 통과지만 livePassed가 false실제 도구가 호출됐는지, 현재 runId에 증거가 있는지 확인합니다. 모델의 거절 설명만으로 Hook 차단을 증명할 수 없습니다.
원본 무결성 실패원본이나 보호 파일이 바뀐 상태입니다. baseline을 덮어쓰지 말고 새 실습 폴더를 생성하세요.
LIMIT 오류차단된 요청도 도구 예산을 소모합니다. 현재 세션의 상태를 확인하고 새 세션에서 교재의 최소 호출 순서로 다시 진행합니다.
승인 화면이 나오지 않음Lv.6인지, 같은 세션에서 검증에 통과했는지, 올바른 hash를 전달했는지, 자동 승인·전역 allow가 없는지 확인합니다. 먼저 tool_error를 읽습니다.
제출 시 EEXIST 또는 중복 오류같은 해시의 영수증이 이미 있습니다. 이미 제출된 산출물을 다시 승인해도 새 영수증을 만들지 않습니다. 전체 재실습은 새 폴더로 진행합니다.
승인 후 파일 변경 오류승인한 버전과 현재 파일이 다릅니다. 파일을 확정한 후 같은 세션에서 다시 검증하고 새 hash로 요청하세요. 남은 예산도 확인합니다.
모델이 도구 호출을 생략함교재의 구체적인 도구 이름과 인자를 사용하고 새 세션에서 시도합니다. 그래도 미호출이면 미확인으로 기록하고 강사에게 모델 호환성 점검을 요청합니다.
